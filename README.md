Welcome to my ongoing journey through the **PortSwigger Web Security Academy**! 

This repository serves as a structured collection of vulnerabilities, exploitation techniques, and mitigation strategies. The modules here correspond to the various categories of web application security flaws identified by PortSwigger.

## 🎯 Project Goal

The primary goal of this repository is to systematically explore, document, and replicate real-world web vulnerabilities. By breaking down complex vulnerabilities into isolated modules, this project aims to create a comprehensive reference guide for modern web application security testing.

## 📂 Repository Structure

This repository is continuously expanding. As I progress through the academy, new vulnerability modules are added. Each module folder contains specific details, notes, and examples for that particular vulnerability class.

Some of the topics covered in this series include:
- **SQL Injection (SQLi)**: Exploiting database queries and uncovering sensitive data.
- **Cross-Site Scripting (XSS)**: Injecting malicious scripts into web pages viewed by other users.
- **Server-Side Request Forgery (SSRF)**: Tricking the server into making arbitrary requests.
- **Cross-Site Request Forgery (CSRF)**: Forcing authenticated users to execute unwanted actions.
- **Authentication & Access Control**: Identifying broken login flows and privilege escalation vectors.
- **API Pentesting**: Exploring hidden endpoints and mass assignment vulnerabilities.

## 🚀 Getting Started

To explore a specific vulnerability, simply navigate to its corresponding directory. Inside, you will find targeted information and examples that demonstrate the core concepts and attack vectors of that flaw.
